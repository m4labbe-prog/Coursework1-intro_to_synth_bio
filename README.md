This repository contains the runnable code for question 4 of the core module 1: Introduction to Synthetic Biology Coursework as well as the list of the random seeds used in the script. 
Note: NumPy and Matplotlib are needed to run this code.
The aim of the task was to reproduce data from the Curtis et al., 2026 paper "Probability, parameters, and duration of immigration and extinction in microbial communities". All the parameters, equations etc. are taken from this paper.
